## Run Locally

No framework or build process is required.

### Option 1 — Open directly

Download/clone the repository and open:

```text
index.html
```

in a modern browser.

### Option 2 — Use VS Code

1. Open the project folder in **VS Code**.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Deploy on GitHub Pages

### 1. Create a GitHub repository

Create a new repository, for example:

```text
prathmesh-portfolio
```

For a personal portfolio, you can also use the special repository name:

```text
CodeiamPrathamesh.github.io
```

if that matches your GitHub username.

### 2. Upload these files

Upload:

```text
index.html
hero-tactical.jpg
README.md
```

Make sure `index.html` and `hero-tactical.jpg` are in the same directory.

### 3. Enable GitHub Pages

In your repository:

**Settings → Pages → Build and deployment**

Choose:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Save the settings.

GitHub will provide your live website address.

## Before Publishing — Important Fix

The current HTML contains a local Windows CV path similar to:

```text
C:\Users\DELL\Desktop\PSG\Prathamesh_Gade_Data_Analyst.pdf
```

That path works only on your computer.

For GitHub Pages, place your CV inside the repository, for example:

```text
assets/Prathamesh_Gade_Data_Analyst.pdf
```

and change the HTML link to:

```html
<a href="assets/Prathamesh_Gade_Data_Analyst.pdf"
   class="btn btn-primary"
   target="_blank">
   Download CV
</a>
```

This will make the CV accessible from your published portfolio.
